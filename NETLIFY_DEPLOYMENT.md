## 📋 **Quick Deployment Steps** (3 Minutes!)

### **Step 1: Push to GitHub**
```bash
git push origin ngroksetup
```

### **Step 2: Sign Up to Netlify**

1. Go to **[app.netlify.com/signup](https://app.netlify.com/signup)**
2. Click **"Sign up with GitHub"** (easiest!)
3. Authorize Netlify to access your repositories

### **Step 3: Import Your Project**

1. After login, click **"Add new site"** → **"Import an existing project"**
2. Click **"Deploy with GitHub"**
3. You may need to authorize Netlify again - click **"Authorize Netlify"**
4. Find and select your **photo-viewer** repository

### **Step 4: Configure Build Settings**

Netlify will auto-detect settings from `netlify.toml`, but verify:

**Site settings:**
- **Branch to deploy:** `ngroksetup` ⚠️ **IMPORTANT:** Change from `main` to `ngroksetup`
- **Build command:** `cd client && npm install && npm run build`
- **Publish directory:** `client/dist`
- **Base directory:** `/` (leave empty or root)

**Environment variables (Optional - already in netlify.toml):**
- Key: `VITE_API_URL`
- Value: `https://photos-poc.onrender.com`

### **Step 5: Deploy!**

1. Click **"Deploy site"** or **"Deploy [your-repo-name]"**
2. Wait 2-3 minutes for build to complete
3. Watch the build logs - you'll see it installing and building

### **Step 6: Get Your URL!**

Once deployed, you'll get a URL like:
- **https://[random-name].netlify.app**

You can customize this:
1. Go to **Site settings** → **Domain management**
2. Click **"Options"** → **"Edit site name"**
3. Change to something like: `photo-viewer-demo.netlify.app`

## 🔧 **How API Proxying Works:**

Your `_redirects` file routes API requests:
```
/api/*  https://photos-poc.onrender.com/api/:splat  200
```

**Flow:**
1. Frontend calls: `https://your-app.netlify.app/api/photos`
2. Netlify proxies to: `https://photos-poc.onrender.com/api/photos`
3. Render backend responds with data
4. Frontend displays photos from Cloudinary

**Result:** ✅ No CORS issues! ✅ Everything works seamlessly!

## 🐛 **Troubleshooting:**

### Build Failed?
**Check these:**
- ✅ Branch is set to `ngroksetup` (not `main`)
- ✅ Build command: `cd client && npm install && npm run build`
- ✅ Publish directory: `client/dist`
- ✅ Check build logs for specific errors

### API Requests Failing?
**Verify:**
- ✅ `_redirects` file exists in `client/public/`
- ✅ It's being copied to `client/dist/` during build
- ✅ Check Network tab in browser DevTools
- ✅ Verify Render backend is running: https://photos-poc.onrender.com/health

### Photos Not Loading?
**Check:**
- ✅ Cloudinary URLs are correct in database
- ✅ Browser console for errors
- ✅ Network tab shows 301 redirects to Cloudinary
